# Background effect provenance

The photo dithering shader is derived from Paper Shaders by Paper Design,
licensed under the Apache License, Version 2.0. A copy is included at
`licenses/PAPER-SHADERS-APACHE-2.0.txt`.

Upstream: https://github.com/paper-design/shaders

Aura's animated variant adds a time-driven spatial wave, blue-noise threshold,
and half-wallpaper dissolve to that image shader. This standalone Helium port
changes the browser integration while retaining those shader calculations.
